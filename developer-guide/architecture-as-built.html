What changed since the original diagram
Runs on WSL2 with nested KVM. The bare-metal / cloud run (M13) and Terraform are not built yet.
Guest runtimes are Python 3.14 and Node.js 24 on Alpine 3.24 (Alpine does not ship 3.12 / 20).
S3 / MinIO only stores function code. Snapshots stay on local disk; backup to S3 was not built.
New Code Store: a local sha256 cache in front of S3; no bucket configured means local disk only.
No Docker anywhere: MinIO is built from source, Prometheus and Grafana run as pinned release binaries.
Isolation is a mode: default none; jailer + cgroups + netns + nftables with --isolation jailer (sudo).
beevmd serves the dashboard at /ui/, with a deploy panel; new API: /api/v1/events (SSE), /node, /me.
Three runners: cold, snapshot, warm (default); per-tenant VM quota; function snapshots built after deploy.
New Events Hub pushes VM, invoke and deploy events to the dashboard through the pool's state hook.
Operator CLI beevmd (tenant, key, snapshot, bench, doctor) next to the user CLI beevm (login, init).
